# mdedit 사용자 가이드

mdedit는 Tauri v2 + React + CodeMirror 6로 만든 크로스 플랫폼 마크다운 에디터 데스크톱 앱입니다. 이 문서는 실제 화면에서 보이는 메뉴·버튼·단축키를 그대로 따라갈 수 있도록 정리한 사용자 매뉴얼입니다.

> 관련 문서: 외부 LLM(ChatGPT 등)에서 만든 마크다운을 mdedit에 붙여넣을 때의 모범 사례는 [USER_MANUAL.md](./USER_MANUAL.md)를 참고하세요. 이 가이드는 앱 자체의 사용법을 다룹니다.

## 1. 시작하기

### 1.1 설치와 실행

개발 환경에서 직접 빌드해 실행하는 경우:

```bash
git clone https://github.com/bjw202/mdedit.git
cd markdown-editor-rust
npm install
npm run dev
```

최초 실행 시 Rust 의존성 컴파일로 5~10분이 걸립니다. 배포용 설치 파일(.dmg / .exe / .deb 등)을 만들려면 `npm run build`를 실행합니다. 플랫폼별 상세 빌드 절차는 저장소 [README](../README.md)를 참고하세요.

### 1.2 첫 화면 구성

앱을 열면 화면은 크게 세 영역으로 나뉩니다.

- **왼쪽 탐색기(사이드바)**: 폴더를 열면 그 안의 파일과 하위 폴더가 트리로 표시됩니다. 파일을 클릭하면 편집기/뷰어에 열립니다.
- **가운데 에디터**: CodeMirror 6 기반 마크다운 편집 영역. 상단에 서식 툴바가 있습니다.
- **오른쪽 미리보기**: 편집 중인 마크다운이 실시간(약 300ms 디바운스)으로 렌더링됩니다.

상단 헤더에는 파일 작업 버튼(New / Save / Save As), Export 드롭다운, 뷰 모드 토글(편집 / 분할 / 미리보기), 이미지 모드 토글, 글꼴 크기 조절(± 스테퍼), 테마 토글(해/달 아이콘), 그리고 설정(톱니) 아이콘이 있습니다.

세 영역 사이 경계는 드래그해서 폭을 자유롭게 조절할 수 있습니다.

### 1.3 뷰 모드 전환

헤더의 세그먼티드 토글로 화면 구성을 바꿉니다.

- **편집**: 에디터만 전체 표시
- **분할**: 에디터 + 미리보기 나란히(기본값)
- **미리보기**: 미리보기만 전체 표시

선택한 모드는 앱을 다시 켜도 그대로 복원됩니다.

### 1.4 AI 기능 전제조건 (중요)

mdedit의 AI 기능은 **로컬에 설치된 Claude Code CLI(`claude` 명령)** 를 통해 동작합니다. 앱 자체 서버는 없으며, 문서 내용은 로컬 CLI 프로세스를 거쳐서만 처리됩니다. AI 기능을 쓰려면 먼저 아래를 준비해야 합니다.

1. 헤더 오른쪽 끝의 **설정(톱니) 아이콘**을 클릭하면 "설정" 다이얼로그가 열리고 첫 섹션이 "AI 도구"입니다.
2. 연결 상태가 자동 감지되어 아래 중 하나로 표시됩니다.
   - **Claude Code ✅ 사용 가능 (v...)** — 바로 사용할 수 있습니다.
   - **연결 필요 — 로그인이 필요해요** — [연결 안내 보기] 버튼으로 온보딩을 진행합니다.
   - **Claude Code가 설치되어 있지 않아요.** — [설치 안내 보기] 버튼으로 온보딩을 진행합니다.
   - **조직 정책으로 AI 기능이 비활성화되어 있어요 (토글 잠금).** — 정책으로 잠긴 상태입니다(1.5 참고).
3. 온보딩 위저드는 4단계로 진행됩니다.
   - **1. 설치**: 표시된 명령 `npm install -g @anthropic-ai/claude-code`를 [복사] 버튼으로 복사(누르면 "복사됨"으로 바뀜)해 터미널에서 실행합니다.
   - **2. 터미널 열기**: Windows는 PowerShell/명령 프롬프트, macOS·Linux는 터미널을 엽니다.
   - **3. 로그인**: 설치 후 안내에 따라 Claude에 로그인합니다.
   - **4. 확인**: [다시 확인] 버튼을 누르면 앱이 상태를 재감지합니다.

처음 "사용 가능" 상태에 진입하면 데이터 전송 고지 배너가 한 번 표시됩니다: "Claude로 AI 기능을 사용합니다. 선택한 텍스트와 문서 일부가 처리를 위해 전송됩니다." [확인]을 누르면 다시 나타나지 않습니다.

### 1.5 AI 켜기/끄기와 정책 잠금

설정 다이얼로그의 "사용 가능" 상태에는 다음 토글이 있습니다.

- **AI 기능 사용** (기본 켜짐): 끄면 ✨ 선택 툴바, 3초 유휴 이어쓰기 힌트, Cmd/Ctrl+Enter 신규 트리거가 모두 사라지고 진행 중인 AI 요청도 즉시 취소됩니다. 순수 편집에 집중하고 싶을 때 사용합니다.
- **고급 모델 사용 (sonnet — 더 정확, 더 느림)**: 켜면 sonnet 모델을, 끄면 기본 haiku 모델을 사용합니다.
- **이어쓰기 짧게 쓰기 (한두 문장만)**: 이어쓰기 응답 분량을 짧게 제한합니다(기본값은 '보통').

조직 정책(환경 변수 `MDEDIT_AI_DISABLED=1` 또는 정책 파일)으로 AI가 비활성화되면 위 토글이 모두 비활성 상태가 되고 옆에 자물쇠(🔒)가 표시됩니다. 정책 잠금은 항상 사용자 토글보다 우선합니다.

## 2. 기본 편집

### 2.1 마크다운 편집과 미리보기

에디터에 마크다운을 입력하면 오른쪽 미리보기에 실시간 렌더링됩니다. 헤딩, 목록, 표, 코드 블록, 링크, 이미지, 수식(KaTeX), Mermaid 다이어그램을 지원합니다. 헤더의 글꼴 크기 스테퍼(−/＋)로 편집기와 미리보기를 함께 확대·축소할 수 있고, 해/달 아이콘으로 라이트/다크 테마를 전환합니다(시스템 설정 자동 연동).

### 2.2 서식 툴바

에디터 상단 툴바 버튼(왼쪽부터):

| 버튼 | 기능 | 단축키 |
| --- | --- | --- |
| **B** | 굵게 | Cmd/Ctrl+B |
| *I* | 이탤릭 | Cmd/Ctrl+I |
| H1 / H2 / H3 | 제목 삽입 | — |
| 목록 | 순서 없는 목록 / 순서 있는 목록 | — |
| 코드 | 코드 삽입 | — |
| 링크 | 링크 삽입 | — |
| 인용 | 인용문(Blockquote) | — |
| 표 삽입 | 8×8 그리드 피커 팝오버 | — |
| 이미지 | 이미지 삽입 | Cmd/Ctrl+Shift+I |

### 2.3 표 삽입 (8×8 그리드 피커)

1. 툴바의 **표 삽입** 버튼(격자 아이콘)을 클릭하면 8×8 격자 팝오버가 열립니다.
2. 격자 위에서 마우스를 움직이면 커서까지의 셀이 하이라이트되고, 아래에 "행 × 열" 크기(예: `3 × 4`)가 표시됩니다.
3. 원하는 크기의 셀을 클릭하면 헤더 행과 구분 행이 포함된 마크다운 표 스켈레톤이 커서 위치에 삽입되고, 첫 헤더 셀이 선택된 상태로 포커스가 돌아옵니다.

팝오버는 바깥을 클릭하거나 Esc를 누르면 닫힙니다.

### 2.4 스크린샷 캡처해서 붙여넣기 (이미지 삽입)

문서에 이미지를 넣는 가장 빠른 방법은 화면을 캡처해 바로 붙여넣는 것입니다.

#### 캡처 → 붙여넣기 (주요 방법)

1. 화면 영역을 클립보드로 캡처합니다.
   - **macOS**: `Cmd+Shift+Ctrl+4` (영역을 클립보드로 복사). `Cmd+Shift+4`는 영역을 파일로 저장하므로, 바로 붙여넣으려면 `Ctrl`을 더한 조합을 쓰세요.
   - **Windows**: `Win+Shift+S` (캡처 도구 → 영역 선택 → 클립보드로 복사).
2. 에디터에서 넣고 싶은 위치를 클릭합니다.
3. **Cmd/Ctrl+V**로 붙여넣습니다.
4. 커서 위치에 마크다운 이미지(`![image](...)`)가 삽입되고, 오른쪽 미리보기에 그림이 즉시 렌더링됩니다.

> 아직 저장하지 않은 새 문서에 이미지를 붙여넣으면, 저장 위치를 정하기 위해 먼저 "다른 이름으로 저장" 다이얼로그가 나타납니다. 저장하면 이어서 이미지가 삽입됩니다.

#### 삽입 모드: 문서에 임베드 vs 파일로 저장

헤더의 **"Image:"** 드롭다운에서 붙여넣기 방식을 고릅니다.

- **Inline** (기본값): 이미지를 base64 데이터 URI로 마크다운에 직접 임베드합니다. 별도 파일이 생기지 않아 **문서 하나로 완결**됩니다. 파일을 그대로 주고받아도 이미지가 따라갑니다. 다만 문서 크기가 커집니다.
- **File**: 이미지를 문서와 같은 폴더의 `./images/` 하위 폴더에 파일로 저장하고, 마크다운에는 상대 경로 링크(`![image](images/...)`)만 넣습니다. 문서 본문이 가볍고 이미지를 따로 관리할 수 있지만, **공유할 때 `images/` 폴더를 함께 전달**해야 합니다.

정리하면, 파일 하나로 끝내고 싶으면 **Inline**, 이미지를 자산으로 분리해 관리하려면 **File**을 선택하세요.

#### 다른 삽입 방법

- **드래그 앤 드롭**: 이미지 파일을 에디터에 끌어다 놓으면 `./images/` 폴더로 복사되고 링크가 삽입됩니다.
- **파일 다이얼로그(Cmd/Ctrl+Shift+I)** 또는 툴바의 이미지 버튼: 파일을 선택하면 `./images/` 폴더로 복사되고 링크가 삽입됩니다.

### 2.5 저장과 파일 관리

- **New (Cmd/Ctrl+N)**: 새 파일
- **Save (Cmd/Ctrl+S)**: 저장
- **Save As (Cmd/Ctrl+Shift+S)**: 다른 이름으로 저장

파일명 옆의 점(●)은 저장되지 않은 변경이 있다는 표시입니다. 미저장 변경이 있는 상태에서 다른 파일을 열려고 하면 경고 다이얼로그가 나타납니다.

왼쪽 탐색기에서는 폴더 열기, 파일 생성·삭제·이름 변경, 하위/상위 폴더 이동(↑ 버튼), 새로고침, 검색을 할 수 있습니다.

### 2.6 내보내기 (Export)

헤더의 **Export** 드롭다운에서 세 가지 형식으로 내보낼 수 있습니다.

- **Export as HTML** — base64 이미지 임베드 포함
- **Export as PDF**
- **Export as DOCX** — 실제 이미지 포함

내용이 없으면 Export 버튼은 비활성화됩니다.

## 3. 뷰어와 지원 파일 형식

mdedit는 탐색기의 모든 파일을 열 수 있고, 확장자에 따라 적절한 뷰어로 라우팅합니다. 아래는 코드에서 확인된 실제 동작입니다.

| 확장자 | 열리는 방식 |
| --- | --- |
| `.md`, `.markdown` | 마크다운 에디터 + 실시간 미리보기(편집 가능) |
| `.html` | 샌드박스 iframe 보기 전용 렌더링(같은 폴더 CSS·이미지·스크립트 로드) |
| `.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp` `.ico` `.avif` | 이미지 뷰어 — 확대/이동(zoom/pan), 체커보드 배경, 픽셀·용량 메타 표시 |
| `.svg` | SVG 뷰어 — 렌더 ↔ 소스 토글, DOMPurify로 정화(sanitize) |
| `.py` `.js` `.mjs` `.cjs` `.ts` `.json` `.jsonl` `.yaml` `.yml` `.toml` `.sh` `.bash` `.css` | 코드 뷰어 — Shiki 구문 강조(보기 전용, 라이트/다크 자동) |
| 그 외 텍스트 파일(예: `.gitignore`, `.log`, `.csv`) | 평문으로 표시 + 편집 가능 |
| 바이너리·읽기 불가 파일(예: `.pdf`, `.zip`) | "미리보기 불가" 플레이스홀더(편집기에 로드하지 않음) |
| 5MB 초과 대용량 파일 | 전체 로드 없이 "미리보기 건너뜀" 안내 |

### Mermaid 다이어그램

마크다운 안의 ` ```mermaid ` 코드 블록은 순서도, 시퀀스, 클래스 다이어그램 등으로 렌더링됩니다. 다이어그램 테마는 앱의 라이트/다크 모드를 따라가며, 테마를 전환하면 이미 렌더된 다이어그램도 즉시 다시 채색됩니다.

### 수식(KaTeX)

인라인 `$...$` 및 블록 `$$...$$` 수식이 KaTeX로 렌더링됩니다.

## 4. AI 어시스턴트

mdedit의 AI는 크게 세 갈래입니다: **✨ 선택 툴바**(선택한 텍스트 변환), **이어쓰기**(문체를 이어받아 계속 쓰기), **섹션 채우기**(빈 헤딩 아래 내용 생성). 모두 결과가 실시간 스트리밍되며, 확정하기 전까지 문서 본문은 바뀌지 않습니다.

> 준비: 4장의 기능은 설정 다이얼로그에서 Claude Code가 "사용 가능"으로 표시되고, "AI 기능 사용" 토글이 켜져 있어야 동작합니다([1.4](#14-ai-기능-전제조건-중요), [1.5](#15-ai-켜기끄기와-정책-잠금) 참고).

### 4.1 ✨ 선택 툴바 — 6가지 프리셋

1. 에디터에서 텍스트를 드래그해 선택하면 선택 끝에 **✨ 버튼**이 나타납니다.
2. ✨ 버튼을 클릭하면 프리셋 메뉴가 열립니다.
   - 로그인되어 있지 않으면 메뉴 대신 "연결 필요" 안내가 뜨고 설정 온보딩이 열립니다.
3. 프리셋을 고르면 원문 아래에 **제안 카드**가 뜨고 결과가 실시간으로 스트리밍됩니다.

프리셋 6종:

| 프리셋 | 언제 쓰나 | 결과 |
| --- | --- | --- |
| 🖊 **다듬기** | 문장을 자연스럽게 교정 | 입력 언어를 유지한 채 다듬은 문장을 제자리 **바꾸기** |
| 📋 **개요로 정리** | 긴 글을 요점/개요로 | 개요 텍스트를 **바꾸기** 또는 **아래 삽입**(기본은 바꾸기) |
| 📊 **표로 만들기** | 나열된 내용을 표로 | 마크다운 표를 **아래 삽입 전용**(원문 보존) |
| 🧜 **다이어그램으로** | 절차·관계를 mermaid로 | mermaid 다이어그램을 **아래 삽입 전용**. 카드 안에서 미리 렌더해 검증하고, 실패 시 자동 재요청, 계속 실패하면 "목록으로" 폴백 제안 |
| ✂️ **짧게 줄이기** | 문단을 간결하게 | 줄인 문장을 제자리 **바꾸기** |
| ✏️ **직접 입력...** | 원하는 지시를 직접 | 입력창에 지시 입력(예: "영어로 번역해줘") 후 Enter |

선택 길이 제한: 2,000자 이하면 모든 프리셋을 쓸 수 있습니다. 다듬기·직접 입력은 2,000자를 넘으면 비활성화되고 "선택이 너무 길어요. 문단 단위로 나눠 선택해주세요." 안내가 뜹니다. 변환 계열(개요·표·다이어그램·짧게)은 2,001~4,000자 구간에서 "아래 삽입 전용"으로만 허용되고, 4,000자를 넘으면 비활성화됩니다.

#### 제안 카드 조작

- **✓ 바꾸기 / ⤵ 아래에 삽입**: 제안을 문서에 적용합니다. 적용은 단일 트랜잭션이라 **Cmd/Ctrl+Z 한 번**으로 원래대로 되돌릴 수 있습니다.
- **↻ (직접 지시)**: 카드 상단 입력칸("✏️ 방향 지시... (예: 더 짧게, 존댓말로)")에 방향을 적고 ↻(또는 Enter)를 누르면 그 지시로 다시 요청합니다.
- **↻ 다시**: 지시 없이 "이전 제안과 다른 방식으로" 다시 요청합니다(연속 3회까지).
- **✕ 취소**: 카드를 닫습니다(스트리밍 중이면 진행 중 요청도 취소).

3회 재요청을 소진하면 "방향을 알려주시면 더 정확해요 (위 입력칸)" 안내와 함께 **⚡ 고급 모델로 다시 시도**(sonnet 1회성) 버튼이 나타납니다.

카드가 뜬 상태에서 원문을 직접 편집하면 "원문이 편집되어 이 제안을 멈췄어요" 배너와 [무시]/[다시 요청]이 나타납니다. 문서가 길어 일부만 참고했을 때는 "문서가 길어 일부만 참고했어요" 고지가 붙습니다. 결과가 원문과 사실상 같으면 "이미 자연스러워서 바꿀 곳이 없어요"라고 알려줍니다.

### 4.2 이어쓰기 (문서 끝 / 자유 위치)

기존 문체를 이어받아 다음 내용을 써 줍니다. 회색 **고스트 텍스트**로 미리 보여주고, 확정해야 문서에 들어갑니다.

트리거:

- **문서 끝**: 문서 맨 끝 빈 줄에 커서를 두고 **Cmd/Ctrl+Enter**를 누르거나, 커서를 3초간 멈추면 나타나는 "**✨ 이어쓰기 ⌘⏎**"(Windows/Linux는 `Ctrl+⏎`) 힌트 알약을 클릭합니다.
- **자유 위치**: 문서 중간 임의 위치에서도 Cmd/Ctrl+Enter 또는 힌트로 이어쓰기가 됩니다. 앞뒤 문맥을 모두 인지해 끊긴 문장부터 자연스럽게 잇고, 뒤 내용을 반복·선점하지 않습니다.
  - 코드 펜스·표 내부에서는 자동 제외되어 트리거되지 않습니다.
  - 리스트·인용 내부에서는 힌트는 뜨지 않지만 Cmd/Ctrl+Enter 수동 트리거는 허용됩니다.
  - 자유 위치 힌트는 문장이 아직 끝나지 않은(마침표 등이 없는) 줄 끝에서만 보수적으로 나타납니다.

진행과 확정:

1. 트리거하면 앵커 위치에 "**✨ 작성 중…**" 플레이스홀더가 펄스로 표시되고, 곧 회색 고스트 텍스트가 스트리밍됩니다.
2. 스트리밍 중에는 **[■ 중지]** 버튼이, 생성이 끝나면 **[✓ 넣기] [✕ 지우기] [↻]** 버튼이 나타납니다.
3. **확정**은 Cmd/Ctrl+Enter(또는 [✓ 넣기]), **버리기**는 Esc(또는 [✕ 지우기])입니다. 확정도 단일 트랜잭션이라 Cmd/Ctrl+Z 한 번으로 되돌릴 수 있습니다.
4. **↻**(완료 후에만 표시)는 같은 종류로 다시 요청합니다.
5. 스트리밍 도중 아무 글자나 입력하면 고스트가 즉시 사라지고 진행 중 요청도 취소됩니다(타이핑 우선).

대기 안내: 요청 후 첫 응답이 8초 넘게 없으면 "아직 생성 중이에요 — 취소할 수 있어요" 문구가 덧붙습니다(가짜 진행률 표시는 없음). 60초가 지나도 응답이 없으면 요청이 타임아웃 처리되어 종료됩니다.

이어쓰기 분량은 설정의 "이어쓰기 짧게 쓰기 (한두 문장만)" 토글로 조절합니다(기본은 '보통').

### 4.3 섹션 채우기

**빈 헤딩 바로 아래 빈 줄**에 커서가 있으면 그 섹션의 내용을 채워 줍니다.

1. `## 소제목` 같은 헤딩을 쓰고 그 아래 빈 줄에 커서를 둡니다.
2. **Cmd/Ctrl+Enter**를 누르거나, 3초 멈춤 시 나타나는 "**✨ 이 섹션 채우기 ⌘⏎**"(Windows/Linux는 `Ctrl+⏎`) 힌트를 클릭합니다.
3. 문서의 전체 헤딩 구조를 참고해 해당 섹션 내용이 고스트로 스트리밍됩니다.
4. 확정([✓ 넣기]/Cmd·Ctrl+Enter), 버리기([✕ 지우기]/Esc), 재요청(↻)은 이어쓰기와 동일합니다.

빈 헤딩 섹션 채우기는 이어쓰기보다 우선합니다.

## 5. 추천 유즈케이스

동영상 시나리오 후보로, 각 단계는 실제 앱 동작과 일치합니다.

### ① 회의 메모를 개요·표로 정리

1. 러프한 회의 메모를 붙여넣습니다.
2. 화이트보드나 화면을 캡처했다면(macOS `Cmd+Shift+Ctrl+4`, Windows `Win+Shift+S`) 원하는 위치를 클릭하고 **Cmd/Ctrl+V**로 스크린샷을 바로 붙여넣습니다.
3. 정리할 문단을 선택 → ✨ → **📋 개요로 정리** → 제안 카드에서 **✓ 바꾸기**.
4. 항목이 나열된 부분을 다시 선택 → ✨ → **📊 표로 만들기** → **⤵ 아래에 삽입**으로 원문 아래에 표를 붙입니다.

### ② 기술 블로그 초안을 이어쓰기로 확장

1. 도입 문단을 몇 줄 써 둡니다.
2. 문단 끝(또는 문서 끝) 빈 줄에서 **Cmd/Ctrl+Enter** → 고스트로 이어지는 내용을 확인.
3. 방향이 맞으면 **[✓ 넣기]**, 아니면 **[↻]** 로 다른 버전 요청. 너무 길면 설정에서 "이어쓰기 짧게 쓰기"를 켭니다.

### ③ README 뼈대 잡고 섹션 채우기

1. `# 프로젝트`, `## 설치`, `## 사용법` 처럼 빈 헤딩만 먼저 나열합니다.
2. 각 헤딩 아래 빈 줄에 커서를 두고 **Cmd/Ctrl+Enter** → **✨ 이 섹션 채우기** 로 섹션별 내용을 생성.
3. 마음에 들면 확정하고, 필요하면 ↻로 다시 요청합니다.

### ④ 긴 문단 다듬기·줄이기 후 다이어그램 생성

1. 장황한 문단을 선택 → ✨ → **🖊 다듬기** 로 문장을 교정(**✓ 바꾸기**).
2. 여전히 길면 다시 선택 → ✨ → **✂️ 짧게 줄이기**.
3. 절차를 설명하는 문단을 선택 → ✨ → **🧜 다이어그램으로** → 카드에서 미리 렌더된 mermaid를 확인하고 **⤵ 아래에 삽입**. (생성이 어려우면 "목록으로" 폴백을 제안합니다.)

### ⑤ 집중 모드: AI 끄고 순수 편집

1. 설정(톱니) → "AI 기능 사용" 토글을 **끔**.
2. ✨ 툴바·이어쓰기 힌트·Cmd/Ctrl+Enter 트리거가 모두 사라지고, 방해 없이 순수 마크다운 편집에 집중합니다.
3. 다시 켜면 즉시 기능이 복원됩니다.

### ⑥ 직접 지시로 번역·톤 변경

1. 문단을 선택 → ✨ → **✏️ 직접 입력...** → "영어로 번역해줘" 입력 후 Enter.
2. 제안 카드에서 결과를 검토하고, 톤을 바꾸고 싶으면 상단 지시칸에 "존댓말로" 같은 방향을 적고 ↻.

## 6. 문제 해결 / FAQ

**Q. ✨ 버튼을 눌러도 "연결 필요"만 뜹니다.**
Claude Code CLI에 로그인되어 있지 않은 상태입니다. 설정(톱니) → [연결 안내 보기]로 온보딩을 진행해 로그인하세요.

**Q. Claude Code가 설치되어 있지 않다고 나옵니다.**
설정 온보딩의 1단계 명령 `npm install -g @anthropic-ai/claude-code`를 복사해 터미널에서 실행한 뒤, 로그인하고 [다시 확인]을 누르세요.

**Q. AI 토글이 회색이고 옆에 자물쇠(🔒)가 있습니다.**
조직 정책(`MDEDIT_AI_DISABLED=1` 환경 변수 또는 정책 파일)으로 AI가 비활성화된 상태입니다. 정책 잠금은 사용자 토글보다 우선하며, 정책을 해제해야 다시 켤 수 있습니다.

**Q. 생성이 너무 오래 걸립니다.**
첫 응답이 8초를 넘기면 "아직 생성 중이에요 — 취소할 수 있어요" 안내가 표시됩니다. 60초가 지나도 응답이 없으면 요청이 자동으로 타임아웃 종료됩니다. 언제든 [■ 중지]/[✕ 취소]로 중단할 수 있습니다.

**Q. AI가 응답이 없거나 오류가 납니다.**
카드에 원인별 안내가 표시됩니다. 로그인 만료면 [연결 안내 보기], 네트워크 문제면 "네트워크에 연결할 수 없어요..."(사내 프록시 환경이면 관리자 문의), 그 외에는 [다시 시도] 버튼이 제공됩니다.

**Q. 제안을 적용하려는데 "원문이 바뀌어 적용할 수 없어요"라고 나옵니다.**
카드를 띄운 뒤 대상 원문이 편집되어 안전하게 적용할 수 없는 경우입니다. 다시 요청하거나 카드를 닫고 새로 선택하세요. 문서는 손상되지 않습니다.

**Q. 프라이버시가 걱정됩니다. 내 문서가 어디로 가나요?**
mdedit는 자체 서버가 없습니다. AI 요청은 로컬에 설치된 Claude Code CLI 프로세스를 통해서만 전송되며, 요청당 CLI 프로세스는 1개, 동시에 1개 요청만 처리됩니다. 다만 선택한 텍스트와 문서 일부는 CLI를 거쳐 Claude로 전송되므로, 최초 사용 시 이 고지 배너가 한 번 표시됩니다.
