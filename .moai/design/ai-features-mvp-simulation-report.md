## 1. 총평 (Executive Summary)

**핵심 상호작용 설계(제안 카드·단일 트랜잭션 undo·프로세스 격리·스트리밍)는 견고하다.** 그러나 5개 독립 시뮬레이션이 서로 다른 각도에서 **동일한 4개의 구조적 문제**에 수렴했다:

| # | 수렴 결론 | 지적한 에이전트 |
|---|---|---|
| S1 | **청중의 역설**: "IT 비전문가" 타깃(P1)과 "개발자 CLI 설치·로그인" 전제가 정면충돌. 진짜 addressable 사용자는 마크다운 파워유저·개발조직 | ④⑤③ |
| S2 | **진짜 킬러는 다듬기가 아니라 mermaid 변환**: "불가능→가능"을 만드는 유일한 차별화. 다듬기·번역은 ChatGPT/Notion AI로 대체 가능한 "느림→빠름" 개선 | ①⑤ |
| S3 | **선택 > 2K 상한의 동작 미정의 = 데이터 손실 경로**: §7 상한이 '컨텍스트'인지 '교체 대상'인지 모호. 장문 선택 + 바꾸기 = 후반부 무손실 삭제 위험 | ①③ |
| S4 | **codex는 동급 출시 불가**: 12초 무스트리밍은 M1 인라인 편집·M2 이어쓰기의 정체성("빠른 마찰 해소", "흐르는 고스트")과 구조적으로 충돌 | ②④⑤ |

시뮬레이션 점수 요약 (1~5): 축 1 평균 **3.6** (편의 3.8 / 직관 3.3 / 유용 3.8), 축 2+3 평균 **2.3** (편의 2.4 / 직관 2.0 / 유용 2.4). **전 영역에서 직관성이 최약** — 특히 "조용한 실패"(무통보 취소, 침묵 절단, stale context)에 결함이 집중됐다.

## 2. "어떤 경우에 정말 잘 활용할 수 있나" — 킬러 시나리오

### 잘 쓰이는 경우 Top 3

1. **절차 서술 문단 → mermaid 다이어그램 → 프리뷰 즉시 렌더** (①C4, ⑤킬러2)
   - ChatGPT 웹은 mermaid *텍스트*만 줌 → 복사→붙여넣기→렌더 확인 3왕복. mdedit는 왕복 0.
   - 비전문가가 mermaid 문법을 손으로 쓰는 건 불가능 → "불가능→가능" 창출.
   - 앱의 기존 mermaid 투자(다크테마, 클러스터 랩 패치)와 직접 시너지. **가장 방어 가능한 킬러.**
2. **웹 AI는 DLP로 차단됐지만 CLI는 승인된 개발조직의 기술문서 작성** (⑤킬러1)
   - 릴리즈노트·README·설계문서. 이 조건에서 mdedit는 "AI를 붙일 수 있는 유일한 마크다운 에디터".
   - 단, "로컬 CLI = 안전" 프레이밍은 부정확 — 프롬프트는 클라우드로 전송됨. 정직한 포지셔닝 필요.
3. **claude CLI를 이미 깔아둔 개발자의 IDE 밖 문서 작업** (⑤킬러3, ④페르소나2)
   - 스펙·회고·노트를 IDE↔브라우저 복붙 왕복 없이 처리. claude 2.7초 스트리밍 경험은 우수(④ 판정 "계속 쓴다").
   - 짧은 문장 다듬기(①C1: 5/5/5), 리스트→표(①C5: 5/5/4)가 이 사용자군에서 고빈도 히트.

### 한두 번 쓰고 이탈하는 경우 Top 3

1. **순수 비전문가의 진입 좌초** — CLI 미설치 시 ✨ 자체가 숨겨져 기능 존재도 모르고 끝. 설치·로그인 벽 통과 확률 0에 수렴 (④페르소나3·4, ⑤이탈1).
2. **codex-only 환경** — 문장 하나 다듬는 데 12초 스피너. 이어쓰기는 "12초 정지 후 통짜 출현"으로 리듬 붕괴 (④페르소나1, ②케이스9).
3. **haiku 품질 기대 불일치(특히 이어쓰기)** — 밋밋한 이어쓰기 + 문체 미상속(②D6) → "ChatGPT가 낫네" 1회 후 이탈 (⑤이탈2).

## 4. "문서 무손상" 원칙 감사 결과 (③)

§9 "어떤 실패도 문서를 건드리지 않는다"는 *실패 시 자동 변경 없음*은 지키지만, **명시적 클릭이 잘못된 위치·범위에 작용하는 4개 경로**에서 사실상 깨진다:

1. exact-match 다중 매칭 → 엉뚱한 첫 번째 위치 교체 (CR5)
2. anchor 앞쪽 편집 시 오프셋 이동 후 dispatch → 이동된 범위 교체 (§4.3은 "범위 침범"만 커버)
3. 고스트 표시 중 Tab 들여쓰기 습관 → 의도치 않은 확정 삽입 (CR2)
4. 장문 선택 절단 교체 → 무손실 삭제 (CR1)

**권고**: 원칙을 *"문서 변경은 사용자 클릭으로만, 변경 위치·범위는 카드에서 본 것과 정확히 일치"*로 강화하고, dispatch 직전 오프셋 재검증을 명세에 추가.

## 5. 전략 판정

### 5.1 타깃 재정의 (⑤·④ 공통 권고)

P1 "IT 비전문가" 전제를 폐기하고 **"마크다운 파워유저·개발조직"**으로 재정렬할 것. 근거:
- CLI 설치·로그인은 비전문가 통과 불가 관문 — 결함이 아니라 **타깃 필터**로 재해석하면 설계가 일관돼짐.
- 애초에 마크다운 에디터 사용자는 순수 비전문가가 아님(비전문가는 Word·한글 사용).
- P1발 결정 중 **diff 금지는 재검토**(진짜 타깃은 diff에 익숙 — 선택적 토글로), **카드·undo·격리 원칙(P5·P6)은 그대로 유효**.

### 5.2 codex 출시 판정 (④)

**claude-first 출시 + codex는 "느림/베타(degraded)" 명시 플래그.** 동급 취급 반대.
- M1 인라인 편집이 codex 최약점(12초 vs 수동 편집)과 정확히 겹침.
- codex는 문서 대화(M3)에 상대적으로 적합(대기가 자연스러운 프레임) — 축별 권장 프로바이더 안내.
- 둘 다 설치 시 기본값은 명시적으로 claude 고정 (H8 해소).

### 5.3 M0+M1 범위 판정 (⑤)

인라인 편집 단독으로는 습관 형성 **부분 부족** — "이미 쓴 문장을 고칠 때만" 발동하는 기능이라 재방문 동력이 약함.
- **권장(택1)**: (a) 시나리오 F "섹션 채우기"를 M1로 승격(M0 스트리밍 재활용, 증분 비용 낮음, 재방문 엔진), 또는 (b) M1을 claude-only로 좁혀 첫인상(2.7초) 방어.
- 축 2 전체는 현 설계(키보드 헤비 + Tab 충돌 + codex 붕괴)로는 **후순위 유지가 옳음** (② 판정: 축 3 > 축 2).
- ↻ 다시 3회 소진 시 "더 좋은 모델(sonnet)로 시도" 인라인 제안 — 품질 이탈을 설정 진입 없이 회수 (⑤제언5).

### 5.4 킬 크라이테리아 (출시 후 실패 판정 지표, ⑤)

| 지표 | 실패 임계 | 죽는 전제 |
|---|---|---|
| AI 활성화율 (CLI 감지 성공/전체) | < 20% | 진입장벽이 청중을 죽임 |
| 제안 채택률 ([바꾸기/적용] 클릭) | < 30% | haiku 품질 불충분 |
| ↻ 다시 3회 소진율 | 상위 다수 | 첫 결과 품질 불만 |
| codex vs claude 세션당 요청 수 | codex ≪ claude | 12초가 UX를 죽임 |
| ✨ 코호트 리텐션 | 중앙값 1~2회 후 급감 | 습관 미형성 |
| mermaid 삽입 성공률 | 사전검증 실패 반복 | 유일 킬러 붕괴 |

## 6. 통합 개선 제안 (우선순위순)

SPEC(M0+M1) 작성 전 반영 권장:

1. **[CR1] 선택 길이 정책 명문화** — "컨텍스트 상한"과 "교체 대상 크기"를 분리 정의. 선택이 상한 초과 시 ✨ 비활성화 + "문단 단위로 나눠 선택하세요". CLI 미처리 결과로 선택 전체를 절대 교체하지 않음.
2. **[CR5+H5] exact-match를 "위치 확정" 상호작용으로 승격** — 다중·0 매칭 모두 자동 적용 금지, fuzzy 최근접 위치로 스크롤+하이라이트 후 "여기를 바꿀까요? [✓]" 확인. anchor 적용도 dispatch 직전 오프셋 재검증.
3. **[CR2] 고스트 확정 키를 Tab에서 분리** (M2 설계 시) — Tab은 들여쓰기 유지, 확정은 인라인 [✓ 넣기] 버튼 + Cmd+Enter 재입력. 힌트를 클릭 가능한 버튼으로(H1 동시 해소).
4. **[CR3+H3] 무통보 취소 전면 제거** — 자동 취소 시 반드시 명시 배너("원문이 편집돼 제안을 멈췄어요 [무시/다시]"). Cmd+S는 AI 요청과 독립(취소는 문서 전환에만). 검토 중 카드는 "동시 1개" 대상에서 제외 명시.
5. **[CR4+④D-1] 연결 온보딩 신설** — "터미널에서 실행" 안내 제거, 로그인 상태 선제 감지(경량 프로브) + 미로그인 시 ✨를 "연결 필요" 상태로 표시 + 단계별 위저드. stderr 오류 분류표(로그인/네트워크/기타)를 §9에 추가.
6. **[S2] mermaid를 전면에** — 온보딩·첫 실행 예시를 "문단→다이어그램"으로. 삽입 전 렌더 검증을 카드 흐름에 명시 설계(실패 시 "텍스트로 정리해드릴까요?" 대체 산출물).
7. **[S4] codex degraded 재배치** — "Codex (느림)" 라벨, 10초 에스컬레이션을 `supports_streaming=false`에는 미적용, "예상 ~15초" 표시, 오프라인/프록시 감지 항목 §9 신설.
8. **[H2] 번역 방향 명시 분리** — "🌐 영어로" / "한국어로" 별도 항목화.
9. **[H4+M7] 대화-문서 동기화** — 편집 발생 시 "문서가 수정되었습니다 — 다시 읽을까요?" 재동기화 프롬프트. 문서 전환 라벨에 휘발성 명시.
10. **[H6+H8] 엔터프라이즈 최소 요건** — 정책 파일/env로 AI 강제 비활성, 자동 선택 시 벤더·데이터 전송 1회 고지 배너.
