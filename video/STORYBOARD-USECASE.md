# mdedit AI 유즈케이스 영상 — 스토리보드 v2.0 (페르소나 케이스)

> 제작: Remotion (React) · 1920×1080 · 30fps · 한국어
> 두 번째 영상(튜토리얼과 별개). 앱 소스(ai-selection-toolbar.ts · diagramIconMarkup.ts ·
> mdedit-components.css)를 시각 재현 기준으로 사용.
> 총 길이: 88초 (2,640프레임 @30fps — 씬별 실측 합계)

## 컨셉 (구속) — v2 개편

기능 사용법(how-to)이 아니라 **페르소나 기반 실무 케이스**로 재구성. 주인공은 "그 사람의
결과물과 마감"이며, 기능은 그 마감을 어떻게 앞당기는지 보여주는 도구다. 각 케이스는 페르소나와
시간 압박을 담은 **상황 카드**로 열고 앱으로 컷인한다. before/after 스토리텔링.

## 페이싱·톤 (구속)

- 페이싱: SPEEDY. 죽은 시간 제거, 빠른 타이핑·전환. 각 케이스의 payoff(간트/표/파이)는 리빌을
  빠르게(약 13~14프레임) 끝내고 완성 상태를 충분히 홀드.
- 톤: "~해요/~요" 어미 전면 금지. 단정한 평서형("~된다"·"~한다") 또는 명사형만 사용.

## 전역 시각 언어

- 튜토리얼 영상과 동일한 디자인 토큰(`src/tokens.ts`)·공용 UI 키트(`src/kit/`)만 사용 — 색·폰트
  하드코딩 금지. 훅/마무리의 암전 배경은 근사 흑색 하드코딩 대신 `darkColors.bg` 토큰 사용,
  그 위 텍스트도 `darkColors.textPrimary/Muted/Faint` 토큰 사용.
- AI 크롬 조각(✨ 선택 툴바 · 프리셋 메뉴 · 8종 다이어그램 플라이아웃 · 제안 카드 · 고스트 텍스트 ·
  간트/파이 차트 · 상황 카드)은 `src/usecase/chrome.tsx`에 앱 실물 기준으로 자립 구현.
- 각 씬은 열려 있는 파일과 파일 탐색기의 선택 강조가 항상 일치한다(케이스 1=`미팅메모.md`,
  케이스 2=`캠페인-결과.md`).
- 대상 플랫폼은 Windows — 모든 단축키 키캡은 **Ctrl**(Ctrl+Enter).

## U0. 훅 (~8초 / 240f)

암전(darkColors.bg) 위 대형 카피. "AI 어시스턴트가 있다는데, / 그래서 뭐가 달라지나" 문제 제기 →
"회의자료 한 장, / 30분 걸리던 일" → "빠르게 쓰고, 자동으로 그리고, 금방 다듬는다".

## C1. 케이스 1 — 영업 페르소나 (~35초 / 1050f)

**상황 카드**: 「영업 · 김대리 / 오후 4시, 고객 미팅 종료 / 내일 오전까지 제안 요약을 정리해 회신」.
이어 하나의 연속된 업무 흐름으로 컷인(파일: `미팅메모.md`):

- **Beat A (메모 → 개요)**: 미팅 날메모 전체 선택 → ✨ → 📋 개요로 정리 → 제안 카드 스트리밍 →
  ✓ 바꾸기 → 정돈된 「제안 요약」 개요.
- **Beat B (일정 → 간트)**: 도입 일정 문단 선택 → ✨ → 🧜 다이어그램으로 → 8종 플라이아웃에서
  **간트 차트** 지정 → 미리보기에 간트 렌더(요구사항/데이터 이관/사용자 교육/정식 오픈 마일스톤).
- **Beat C (이어쓰기)**: 맺음 문장에서 멈춤 → **Ctrl+Enter** → 회색 고스트 스트리밍 → 확정.

(v1의 메모 정리·다이어그램·이어쓰기 소재를 한 영업 스토리로 흡수 — 컴포넌트/비트 재사용.)

## C2. 케이스 2 — 홍보 페르소나 (~35초 / 1050f)

**상황 카드**: 「홍보 · 박주임 / 캠페인 종료 다음 날, 보고 회의 1시간 전 / 채널별 성과를 표와
차트로 정리해 보고」. 컷인(파일: `캠페인-결과.md`):

- **Beat A (지표 → 표)**: 채널별 지표 날메모 전체 선택 → ✨ → 📊 표로 만들기 → 제안 카드 →
  ✓ 바꾸기 → 채널/노출/클릭/전환 4열 표 렌더.
- **Beat B (비중 → 파이)**: 채널 비중 문단 선택 → ✨ → 🧜 다이어그램으로 → 8종 플라이아웃에서
  **파이 차트** 지정 → 미리보기에 파이 차트 렌더(인스타 40 / 유튜브 25 / 블로그 20 / 이메일 15).
- **Beat C (이어쓰기)**: 보고용 한 줄 요약을 **Ctrl+Enter** 이어쓰기로 마무리.

(신규 시나리오 — 두 번째 플라이아웃 종류 = 파이 차트, 그리고 📊 표로 만들기를 시연.)

## U4. 마무리 (~10초 / 300f)

두 페르소나/케이스를 반영한 리캡 칩 3개(영업 · 제안 요약 + 일정표 / 홍보 · 성과 표 + 비중 차트 /
어디서나 · 막힌 문장 잇기) → 요약 카피 "쓰는 시간은 줄이고, 다듬는 시간만 남긴다" → 로고 `mdedit`
+ 태그라인 "AI 어시스턴트 · 로컬 Claude Code CLI로 동작".

## 기술 규약

- 쓰기 담당 파일: `src/usecase/*`(신규), `STORYBOARD-USECASE.md`(신규), `Root.tsx`(가산 등록),
  `README.md`(가산 문서). 튜토리얼의 `scenes/*`·`STORYBOARD.md`는 무변경.
- 컴포지션: 씬별 개별(`U0`·`C1`·`C2`·`U4`) + 최종 `UseCase`(전체 이어붙임). `usecase/manifest.ts`가
  확장점 — 씬을 배열에 추가하면 `UseCase`가 자동으로 이어붙인다(`Root.tsx` 무변경).
- 렌더 검증: `npm run render -- UseCase out/mdedit-ai-usecase.mp4` 성공이 완료 조건.
  (헤드리스 풀 페이지 로딩이 간헐적으로 실패하면 `--concurrency=1`로 재시도.)
