# mdedit tutorial video (Remotion)

Standalone Remotion project for the mdedit tutorial video. Independent of the
app's own `package.json` — install and run everything from inside `video/`.

Binding creative brief: `../STORYBOARD.md`. App layout facts: `../docs/USER_GUIDE.md` §1.

## Setup

```bash
cd video
npm install
```

## Preview (Remotion Studio)

```bash
npm run start
```

Opens an interactive preview. Pick the `S0` composition to preview the intro
scene alone, or `Full` to preview the entire video (scenes sequenced from
`src/scenes/manifest.ts`).

## Render

```bash
npm run render -- S0 out/s0.mp4      # single scene
npm run render -- Full out/full.mp4  # entire video
```

## Type check

```bash
npm run typecheck
```

## Project structure

- `src/tokens.ts` — design tokens ported from the app's real CSS (colors,
  fonts, spacing, radii, layout). Every scene must style exclusively from
  this file — never hardcode a color or font.
- `src/kit/` — shared UI kit (`AppFrame`, `HeaderBar`, `FileExplorer`,
  `EditorPane` + `TypingText`, `PreviewPane` + block components,
  `SubtitleBar`, `SceneChip`, `CursorPointer`, `Keycap`, `Highlight`).
- `src/scenes/` — one file per storyboard scene (`S0Intro.tsx`, and later
  `S1...`, `S2a...`, `S3a...`, `S4...`).
- `src/scenes/manifest.ts` — the **extension point**. See below.
- `src/Root.tsx` — registers the `S0` (per-scene) and `Full` (entire video)
  compositions. Reads `manifest.ts` to build `Full`; **do not edit this file
  to add scenes**.

## How to add a scene (for later units)

1. Create `src/scenes/SXFoo.tsx` exporting a component with no required
   props (it may freely call `useCurrentFrame()` / `useVideoConfig()` —
   Remotion resets the local frame counter to `0` at the start of its
   `<Sequence>`) plus a `SX_DURATION_IN_FRAMES` constant. Follow
   `S0Intro.tsx` as the reference pattern.
2. In `src/scenes/manifest.ts`, import the component + duration constant and
   push `{ id: 'SX', component: SXFoo, durationInFrames: SX_DURATION_IN_FRAMES }`
   onto `sceneManifest`, in storyboard order.
3. (Optional but recommended) Register an individual `<Composition id="SX" .../>`
   in `Root.tsx` for standalone preview/render of just that scene — this is
   additive, not a change to the `Full` wiring.
4. Run `npm run start` to preview, `npm run render -- SX out/sx.mp4` to render
   just the new scene, or `npm run render -- Full out/full.mp4` for the whole
   video.

`Root.tsx`'s `Full` composition never needs to change — it derives its total
duration and its list of `<Sequence>`s entirely from `sceneManifest`.
