# mdedit 사용법 영상 — 스토리보드 v1.0

> 제작: Remotion (React) · 1920×1080 · 30fps · 한국어
> 원천 자료: `docs/USER_GUIDE.md`(대본 원본), 앱 소스 CSS/컴포넌트(시각 재현 기준)
> 총 길이: 약 4분 35초 (8,255프레임 @30fps — 씬별 실측 합계)

## 전역 시각 언어

- 앱의 실제 디자인 토큰(색·폰트·간격·라운딩)을 `src/` CSS에서 추출해 `video/src/tokens.ts`로 공유 — 모든 씬이 이 토큰만 사용
- 앱 화면은 공용 `AppFrame` 컴포넌트(헤더 + 파일 탐색기 + 에디터/프리뷰 영역)로 재현, 씬마다 내용물만 교체
- 타이핑 효과: 실제 타이핑 리듬(가변 간격), 커서 블링크 포함
- 전환: 페이드/슬라이드 최소주의. 과한 모션 금지(앱 성격과 일치)
- 자막: 하단 자막 바(전 씬 공통 컴포넌트), 씬 타이틀은 좌상단 칩

## S0. 인트로 (~8초)

로고/앱 이름 "mdedit" 페이드인 → 한 줄 태그라인 "가볍고 빠른 마크다운 편집기" → 이번 영상 목차 2개 칩(마크다운 기초 · 화면 사용법)이 순차 팝.

AI 어시스턴트는 인트로 목차에 넣지 않는다. S3a 히어로 리빌에서 완전한 깜짝 공개로 처리하므로, 인트로는 AI 를 이름으로도 암시로도 노출하지 않는다(수정 F3, 커밋 `32ca014`). 아웃트로(S4)에서는 3개 칩을 모두 보여주며 마무리한다.

## S1. 마크다운 문법 쇼케이스 (~60초)

화면을 좌(에디터)/우(미리보기)로 분할한 AppFrame. 좌측에 문법이 타이핑되면 우측에 즉시 렌더 결과가 나타난다. 항목당 8~10초, 총 6개:

1. `# 제목` — H1~H3 순차 타이핑
2. `**굵게** *기울임* ~~취소선~~`
3. `- 목록` / `1. 번호 목록` (중첩 1단 포함)
4. 표 (3×2 간단 표 — S2의 표 삽입 버튼 복선)
5. 코드 블록 (```js 한 줄) + 인라인 `code`
6. 이미지 `![](...)` + 링크 — 미리보기에 실제 이미지 렌더
   (보너스 2초: mermaid 코드펜스 → 다이어그램 렌더 — "다이어그램도 됩니다" 자막 한 줄)

## S2. UI 투어 (~95초)

**S2a. 첫 화면 해부 (15초)**: AppFrame 전체 표시 → 영역별 하이라이트 순회(① 파일 탐색기 ② 에디터 ③ 헤더 도구들). 각 하이라이트에 라벨 콜아웃.

**S2b. 파일 탐색기 (20초)**: 폴더 트리에서 폴더 펼침 → `회의록.md` 클릭 → 에디터에 내용 로드. 이미지 파일(`.png`) 클릭 → 이미지 뷰어로 열림("md가 아닌 파일은 뷰어로 열립니다" 자막). USER_GUIDE §3 지원 형식 표에서 소재 선택.

**S2c. 보기 모드 3종 (25초)**: 헤더의 모드 토글을 커서가 클릭 — 편집 전용 → 둘 다 보기(분할) → 미리보기 전용. 각 모드에서 레이아웃이 실제처럼 전환. "글 쓸 땐 편집, 검토할 땐 미리보기, 평소엔 둘 다" 자막.

**S2d. 표 삽입 + 스크린샷 붙여넣기 (15초)**: 툴바 표 버튼 → 8×8 그리드 피커 호버(3×4 하이라이트) → 클릭 → 표 스켈레톤 삽입. 이어서 `Cmd+V` 키 표시 → 스크린샷 이미지가 마크다운으로 삽입 + 미리보기 렌더("캡처해서 바로 붙여넣으세요" 자막).

**S2e. 내보내기 PDF·HTML (20초)**: 헤더의 `Export ▾` 버튼(공용 kit 무수정, 이 씬 전용 오버레이)을 커서가 클릭 → 드롭다운 3항목(앱과 동일 영문 라벨·순서: `Export as HTML` / `Export as PDF` / `Export as DOCX`). `Export as PDF` 선택 → 간결한 "PDF로 저장" 인쇄/저장 다이얼로그 목업 → **PDF 뷰어 창 목업**(제목 바 `회의록.pdf`, 페이지 여백)에 문서가 렌더된 결과. 이어 다시 `Export as HTML` → **브라우저 창 목업**(주소창 `file:///…/회의록.html`)에서 같은 문서가 열린 모습. 문서 소재는 S2b의 `회의록.md` 재사용(수미상관). DOCX는 드롭다운 노출만, 시연은 PDF·HTML 두 경로. 자막 "~요" 레지스터("문서는 PDF·HTML·DOCX로 내보낼 수 있어요" / "결과물은 어디서든 그대로 열려요"). 창 목업은 tokens.ts만으로 스타일링.

## S3. AI 부록 (~95초)

**S3a. 히어로 리빌 (12초)**: 화면 암전 → "그리고, 하나 더." 텍스트 → ✨ 파티클과 함께 "AI 어시스턴트" 대형 타이틀 리빌(히어로 페이지 느낌 — 이 씬만 모션 허용치 상향). 하단에 작은 명판: "로컬 Claude Code CLI로 동작 · 문서는 로컬 CLI를 통해서만 전송".

**S3b. 기능 몽타주 (25초)**: 4개 기능 카드가 순차 등장, 각 카드에 미니 데모 루프:
- ✨ 선택 툴바 — 텍스트 선택 → ✨ → 프리셋 6종 메뉴(🖊📋📊🧜✂️✏️). 🧜 다이어그램으로에 호버하면 오른쪽으로 종류 플라이아웃(8항목: 자동(AI 판단) + 순서도·시퀀스·간트·클래스·상태·파이·마인드맵 7종, 각 단색 스켈레톤 아이콘)이 열려 간트 차트를 고른다 — 플라이아웃이 열린 동안 카드를 카메라 푸시인(zoom)으로 확대해 8항목이 1080p에서 편하게 읽히게 강조. 종류를 직접 지정(SPEC-AI-008)
- 이어쓰기 — 커서 끝 `Cmd+Enter` → 회색 고스트 스트리밍 → 확정
- 섹션 채우기 — 빈 헤딩 아래 → 고스트 채움
- 설정 — AI 켜기/끄기 토글 · 고급 모델 · 길이 옵션 ("Claude 전용" 명시 자막)

**S3c. 유즈케이스 시연 2종 (50초)**: USER_GUIDE §5에서 발췌, AppFrame 실물 재현으로 처음부터 끝까지:
- **UC1 회의 메모 정리 (25초)**: 날것 메모 붙여넣기 → 스크린샷 `Cmd+V` → 전체 선택 → ✨ → 📋 개요로 정리 → 제안 카드 스트리밍 → [바꾸기] → 깔끔한 문서로 변신
- **UC2 블로그 초안 이어쓰기 (25초)**: 쓰다 만 문단 끝 3초 멈춤 → "✨ 이어쓰기" 힌트 알약 등장 → 클릭 → 고스트 스트리밍 → `Cmd+Enter` 확정 → 이어서 ↻ 재요청으로 다른 버전 받기

## S4. 아웃트로 (~10초)

기능 요약 3줄 칩 재등장(마크다운 기초 · 화면 사용법 · AI 어시스턴트) → 태그라인 "가볍고 빠른 마크다운 편집기" 리프라이즈 → 로고 아웃.

매뉴얼 경로 안내("docs/USER_GUIDE.md …")는 넣지 않는다. 마무리를 태그라인 리프라이즈로 대체해 S0 와 수미상관을 만든다(수정 F6, 커밋 `d872ba7`).

## 기술 규약

- `video/`는 독립 npm 프로젝트(Remotion 최신 안정판). 앱 `package.json` 무변경
- 컴지션: 씬별 개별 `Composition` + 최종 `Full` 컴포지션(전체 이어붙임) 등록 → 씬 단위 미리보기·부분 렌더 가능
- 공용 컴포넌트: `AppFrame`, `FileExplorer`, `EditorPane`(타이핑 지원), `PreviewPane`, `HeaderBar`, `SubtitleBar`, `CursorPointer`(가짜 마우스), `Keycap`(단축키 표시)
- 각 씬 담당자는 STORYBOARD의 해당 절 + USER_GUIDE 해당 장을 읽고, 라벨·단축키는 USER_GUIDE 표기를 그대로 사용(재발명 금지)
- 렌더 검증: `npx remotion render Full out/mdedit-guide.mp4` 성공이 완료 조건
